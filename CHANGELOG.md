# Changelog

All notable project milestones are documented here.

## 0.1.0 — 2026-10-07

First public open-source milestone for Legocraft.

### Included

- Browser-based 3D brick-building workspace
- Desktop and touch interaction
- Brick placement, movement, rotation, recoloring, and deletion
- Multiple brick sizes and custom shapes
- Solo, multi-object, and connected-group selection
- Copy/paste, undo, and redo
- Built-in structure presets
- Local browser persistence
- JSON project save/import
- GLB export
- PNG screenshot export
- Experimental WebXR interaction
- VR controller input, haptics, menus, locomotion, and snap turning
- MIT license
- Contributor guide
- Architecture guide
- Security policy
- GitHub Actions CI for install, tests, type-check, and production build

### Current limitations

- Meta Quest hardware QA has not yet been completed
- WebXR compatibility remains experimental
- No formal cross-browser compatibility matrix yet
- No formal touch-device compatibility matrix yet
- `App.tsx` and `Scene.tsx` remain large integration files and are candidates for future modularization
