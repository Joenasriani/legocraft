React Three Fiber, Three.js और WebXR से बना एक ओपन-सोर्स ब्राउज़र-आधारित 3D ब्रिक-बिल्डिंग सैंडबॉक्स।

डेस्कटॉप या टच कंट्रोल से ब्राउज़र में डिजिटल ब्रिक संरचनाएँ बनाएं और संपादित करें, प्रोजेक्ट सेव और दोबारा लोड करें, अपनी रचनाएँ एक्सपोर्ट करें और उसी वर्कस्पेस को WebXR में प्रयोग करें।

> **प्रोजेक्ट स्थिति:** प्रायोगिक। डेस्कटॉप और टच इंटरैक्शन लागू हैं। WebXR कार्यक्षमता मौजूद है, लेकिन वास्तविक Meta Quest हार्डवेयर पर QA अभी पूरा नहीं हुआ है। `docs/QUEST_QA.md` देखें।

## आज़माएँ

लाइव एप्लिकेशन: https://legocraftvr.vercel.app/

## डेवलपर्स के लिए

Legocraft ब्राउज़र-आधारित 3D निर्माण प्रणाली का निरीक्षण योग्य उदाहरण भी है: ग्रिड-स्नैप्ड प्लेसमेंट, जनरेटेड ब्रिक ज्योमेट्री, कनेक्टेड-ऑब्जेक्ट चयन, लोकल पर्सिस्टेंस, GLB एक्सपोर्ट और प्रायोगिक WebXR कंट्रोलर इंटरैक्शन एक ही React Three Fiber कोडबेस में मौजूद हैं।

- [आर्किटेक्चर देखें](docs/ARCHITECTURE.md)
- [योगदान दें](CONTRIBUTING.md)
- [WebXR / Quest QA मैट्रिक्स देखें](docs/QUEST_QA.md)

## फीचर्स

- स्नैप्ड 3D बिल्डिंग ग्रिड पर ब्रिक्स रखें, मूव करें, रोटेट करें, रंग बदलें और हटाएँ
- कई आयताकार ब्रिक आकार, साथ में राउंड, कोन, डोम, स्लोप, कर्व्ड, वेज, ट्रायंगल और आर्च आकृतियाँ
- सोलो, मल्टी-ऑब्जेक्ट और कनेक्टेड-ग्रुप चयन
- कॉपी/पेस्ट, अनडू और रीडू
- बिल्ट-इन प्रीसेट्स: Horse, Sheep, Car, Road, Mountain, Tree, Cabin, Water Well, Pine Tree और Castle
- ब्राउज़र में लोकल पर्सिस्टेंस
- प्रोजेक्ट डेटा को `.json` के रूप में सेव और इंपोर्ट करना
- वर्तमान संरचना को `.glb` के रूप में एक्सपोर्ट करना
- स्क्रीनशॉट `.png` के रूप में एक्सपोर्ट करना
- डेस्कटॉप और टच इंटरैक्शन
- Orbit, Pan और Zoom कैमरा मोड
- सेव, कॉपी/पेस्ट, डिलीट और एडिटिंग के लिए कीबोर्ड शॉर्टकट
- स्टार्टअप पर लोकली सेव किए गए बिल्ड्स की ऑटोमेटिक पुनर्स्थापना
- कंट्रोलर इंटरैक्शन, हैप्टिक्स, लोकोमोशन, स्नैप टर्न और VR मेनू के साथ प्रायोगिक WebXR मोड

## लोकली चलाएँ

### आवश्यकताएँ

- Node.js 22 अनुशंसित
- npm
- WebGL सपोर्ट वाला ब्राउज़र

### इंस्टॉल

```bash
git clone https://github.com/Joenasriani/legocraft.git
cd legocraft
npm install
```

### डेवलपमेंट सर्वर शुरू करें

```bash
npm run dev
```

Vite डेवलपमेंट सर्वर पोर्ट `3000` के लिए कॉन्फ़िगर है।

सफल पहली रन में ब्राउज़र में 3D बिल्डिंग वर्कस्पेस खुलना चाहिए और ब्रिक्स को रखने व बदलने की अनुमति मिलनी चाहिए।

### प्रोजेक्ट वेरिफाई करें

```bash
npm run test
npm run lint
npm run build
```

ये कमांड `package.json` में परिभाषित हैं और Node.js 22 पर GitHub Actions द्वारा वेरिफाई किए जाते हैं।

## प्रोजेक्ट फाइलें और एक्सपोर्ट

- `.json` प्रोजेक्ट सेव/इंपोर्ट
- `.glb` 3D एक्सपोर्ट
- `.png` स्क्रीनशॉट
- ऑटोमेटिक लोकल ब्राउज़र पर्सिस्टेंस

स्क्रीनशॉट कैप्चर best-effort है और ब्राउज़र के WebGL व्यवहार पर निर्भर हो सकता है।

## वेरिफिकेशन और कम्पैटिबिलिटी

GitHub Actions वर्तमान में Node.js 22 पर इन कमांड्स से रिपॉज़िटरी को वेरिफाई करता है:

- `npm ci`
- `npm run test`
- `npm run lint`
- `npm run build`

वर्तमान कम्पैटिबिलिटी स्थिति:

| वातावरण | स्थिति |
| --- | --- |
| प्रोडक्शन बिल्ड | CI द्वारा वेरिफाइड |
| ऑटोमेटेड टेस्ट | CI द्वारा वेरिफाइड |
| TypeScript चेक | CI द्वारा वेरिफाइड |
| डेस्कटॉप ब्राउज़र इंटरैक्शन | लागू; औपचारिक क्रॉस-ब्राउज़र मैट्रिक्स अभी नहीं |
| टच इंटरैक्शन | लागू; औपचारिक डिवाइस मैट्रिक्स अभी नहीं |
| WebXR | प्रायोगिक |
| Meta Quest हार्डवेयर | वास्तविक हार्डवेयर पर अभी परीक्षण नहीं |

## WebXR स्थिति

WebXR इंटरैक्शन लागू है, जिसमें कंट्रोलर इनपुट, हैप्टिक फीडबैक, VR मेनू, लोकोमोशन कंट्रोल और स्नैप टर्न शामिल हैं।

वास्तविक Meta Quest हार्डवेयर परीक्षण **अभी तक** पूरा नहीं हुआ है, इसलिए Quest-विशिष्ट कम्पैटिबिलिटी और प्रदर्शन को प्रायोगिक माना जाना चाहिए, गारंटीड नहीं।

वर्तमान हार्डवेयर QA मैट्रिक्स के लिए [`docs/QUEST_QA.md`](docs/QUEST_QA.md) देखें।

## Legocraft पर आगे बनाएं

कोई भी विचार स्वागत योग्य है यदि वह वास्तविक सुधार, प्रयोग, फीचर, डिज़ाइन, टूल, प्रदर्शन लाभ, एक्सेसिबिलिटी लाभ या उपयोगी विस्तार दे सकता है।

वर्तमान गेम शुरुआत है, सीमा नहीं।

प्रोजेक्ट को एक्सप्लोर या एक्सटेंड करने के ठोस तरीके:

- **खेलें:** मौजूदा बिल्डर आज़माएँ और ऐसा इंटरैक्शन या वर्कफ़्लो पहचानें जिसे बेहतर किया जा सके।
- **कोड देखें:** संबंधित सबसिस्टम खोजने के लिए [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) का उपयोग करें।
- **ब्रिक जोड़ें:** ब्रिक परिभाषाएँ और जनरेटेड ज्योमेट्री बढ़ाएँ।
- **प्रीसेट बनाएँ:** मौजूदा प्रीसेट सिस्टम से पुन: उपयोग योग्य संरचना जोड़ें और वेलिडेट करें।
- **इंटरैक्शन सुधारें:** डेस्कटॉप, टच, चयन, एडिटिंग या कैमरा व्यवहार पर काम करें।
- **WebXR टेस्ट करें:** Quest QA प्रक्रिया चलाएँ और वास्तविक हार्डवेयर परिणाम रिपोर्ट करें।
- **XR सुधारें:** कंट्रोलर कम्पैटिबिलिटी, लोकोमोशन, हैप्टिक्स, VR UI या प्रदर्शन पर काम करें।
- **विश्वसनीयता बढ़ाएँ:** प्लेसमेंट, चयन, प्रीसेट्स या साझा डोमेन लॉजिक के लिए केंद्रित टेस्ट जोड़ें।
- **Issue खोलें:** बड़े बदलाव या पुनरुत्पाद्य सीमाओं पर इंप्लीमेंटेशन से पहले चर्चा करें।
- **Pull Request भेजें:** बदलाव को केंद्रित रखें और मौजूदा CI कमांड चलाएँ।

Legocraft MIT License के तहत ओपन सोर्स है। आप [`LICENSE`](LICENSE) की शर्तों के अनुसार fork, modify, extend और redistribute कर सकते हैं। योगदान वर्कफ़्लो के लिए [`CONTRIBUTING.md`](CONTRIBUTING.md) देखें।

### क्रिएटिव और स्पैशियल योगदान

हर उपयोगी योगदान के लिए कोडिंग आवश्यक नहीं है। डिज़ाइनर और टेक्निकल आर्टिस्ट GitHub Issue के माध्यम से प्रीसेट संरचनाएँ, स्पैशियल कंपोज़िशन, नई आकृति अवधारणाएँ, इंटरैक्शन फ्लो, निर्माण चुनौतियाँ या एक्सेसिबिलिटी सुधार प्रस्तावित कर सकते हैं। स्पष्ट स्केच, डायग्राम, रेफरेंस लेआउट और व्यवहार नोट्स उपयोगी हैं जब वे मौजूदा बिल्डर के अनुकूल किसी चीज़ का वर्णन करते हैं।

स्वीकृत योगदान Git हिस्ट्री और Pull Request रिकॉर्ड के माध्यम से क्रेडिट किए जाते हैं; यदि कोई अन्य व्यक्ति स्वीकृत अवधारणा को कोड में बदलता है, तो प्रस्ताव के लेखक को इंप्लीमेंटेशन चर्चा में संदर्भित किया जाना चाहिए।

### WebXR / Quest फ्रंटियर

Legocraft में पहले से प्रायोगिक WebXR इंटरैक्शन, कंट्रोलर इनपुट, लोकोमोशन, हैप्टिक्स, VR मेनू और XR-विशिष्ट बिल्डिंग वर्कफ़्लो मौजूद हैं। वास्तविक Meta Quest हार्डवेयर वेलिडेशन अभी खुला है। XR लेयर डॉक्यूमेंटेड है और जानबूझकर एक्स्टेंसिबल रखी गई है ताकि डेवलपर्स इसे टेस्ट, सुधार, ऑप्टिमाइज़ या आगे बढ़ा सकें।
