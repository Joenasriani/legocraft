بيئة بناء ثلاثية الأبعاد تعتمد على المكعبات وتعمل داخل المتصفح، مبنية باستخدام React Three Fiber وThree.js وWebXR.

يمكنك بناء وتعديل هياكل رقمية بالمكعبات مباشرة في المتصفح باستخدام سطح المكتب أو اللمس، وحفظ المشاريع وإعادة فتحها وتصديرها وتجربة مساحة العمل نفسها في WebXR.

> **حالة المشروع:** تجريبية. تفاعل سطح المكتب واللمس مُنفّذ. وظائف WebXR موجودة، لكن لم يتم بعد إجراء اختبارات فعلية على أجهزة Meta Quest. راجع `docs/QUEST_QA.md`.

## جرّبه

التطبيق المباشر: https://legocraftvr.vercel.app/

## للمطورين

Legocraft هو أيضًا مثال مفتوح يمكن فحصه لنظام بناء ثلاثي الأبعاد داخل المتصفح: وضع العناصر على شبكة مع snap، هندسة مكعبات مولّدة، تحديد العناصر المتصلة، الحفظ المحلي، تصدير GLB، وتفاعل تجريبي مع وحدات تحكم WebXR ضمن قاعدة كود واحدة مبنية بـ React Three Fiber.

- [استكشاف المعمارية](docs/ARCHITECTURE.md)
- [المساهمة](CONTRIBUTING.md)
- [مراجعة مصفوفة QA الخاصة بـ WebXR / Quest](docs/QUEST_QA.md)

## الميزات

- وضع وتحريك وتدوير وتغيير لون وحذف المكعبات على شبكة بناء ثلاثية الأبعاد
- أحجام متعددة من المكعبات المستطيلة إضافة إلى أشكال دائرية ومخروطية وقباب ومائلة ومنحنية وإسفينية ومثلثة وأقواس
- تحديد فردي ومتعدد ومجموعات متصلة
- نسخ/لصق وتراجع وإعادة
- قوالب جاهزة: حصان، خروف، سيارة، طريق، جبل، شجرة، كوخ، بئر ماء، شجرة صنوبر وقلعة
- حفظ محلي داخل المتصفح
- حفظ واستيراد بيانات المشروع بصيغة `.json`
- تصدير الهيكل الحالي بصيغة `.glb`
- تصدير لقطات شاشة بصيغة `.png`
- تفاعل على سطح المكتب واللمس
- أوضاع كاميرا Orbit وPan وZoom
- اختصارات لوحة مفاتيح للحفظ والنسخ/اللصق والحذف والتحرير
- استعادة تلقائية للبناءات المحفوظة محليًا عند بدء التشغيل
- وضع WebXR تجريبي مع وحدات تحكم واهتزازات ولمس حسي وحركة وSnap Turn وقوائم VR

## ملفات المشروع والتصدير

- حفظ/استيراد مشروع `.json`
- تصدير ثلاثي الأبعاد `.glb`
- لقطات شاشة `.png`
- حفظ محلي تلقائي داخل المتصفح

التقاط الشاشة يعمل بأفضل جهد وقد يعتمد على سلوك WebGL في المتصفح.

## التحقق والتوافق

يتحقق GitHub Actions حاليًا من المستودع على Node.js 22 باستخدام:

- `npm ci`
- `npm run test`
- `npm run lint`
- `npm run build`

حالة التوافق الحالية:

| البيئة | الحالة |
| --- | --- |
| بناء الإنتاج | متحقق منه عبر CI |
| الاختبارات الآلية | متحقق منها عبر CI |
| فحص TypeScript | متحقق منه عبر CI |
| تفاعل متصفح سطح المكتب | مُنفّذ؛ لا توجد مصفوفة رسمية عبر المتصفحات بعد |
| التفاعل باللمس | مُنفّذ؛ لا توجد مصفوفة أجهزة رسمية بعد |
| WebXR | تجريبي |
| أجهزة Meta Quest | لم يتم اختبارها بعد على جهاز حقيقي |

## حالة WebXR

تفاعل WebXR مُنفّذ، بما في ذلك إدخال وحدات التحكم والاهتزازات وقوائم VR والتحكم في الحركة وSnap Turn.

لم يتم **بعد** إجراء اختبار حقيقي على أجهزة Meta Quest، لذلك يجب اعتبار التوافق والأداء الخاصين بـ Quest تجريبيين وغير مضمونين.

راجع [`docs/QUEST_QA.md`](docs/QUEST_QA.md) لمصفوفة QA الحالية للأجهزة.

## البناء فوق Legocraft

أي فكرة مرحب بها إذا كانت تستطيع إنتاج تحسين حقيقي أو تجربة أو ميزة أو تصميم أو أداة أو مكسب أداء أو تحسين وصول أو امتداد مفيد.

اللعبة الحالية هي نقطة البداية وليست السقف.

طرق عملية لاستكشاف المشروع أو توسيعه:

- **العب:** جرّب أداة البناء الحالية وحدد تفاعلًا أو سير عمل يستحق التحسين.
- **استكشف الكود:** استخدم [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) للوصول إلى النظام الفرعي المناسب.
- **أضف مكعبًا:** وسّع تعريفات المكعبات والهندسة المولدة.
- **أنشئ قالبًا:** أضف بنية قابلة لإعادة الاستخدام وتحقق منها باستخدام نظام القوالب الحالي.
- **حسّن التفاعل:** اعمل على سطح المكتب أو اللمس أو التحديد أو التحرير أو الكاميرا.
- **اختبر WebXR:** نفّذ خطوات QA الخاصة بـ Quest وسجل نتائج من جهاز حقيقي.
- **حسّن XR:** اعمل على توافق وحدات التحكم أو الحركة أو اللمس الحسي أو واجهة VR أو الأداء.
- **حسّن الاعتمادية:** أضف اختبارات مركزة للوضع أو التحديد أو القوالب أو المنطق المشترك.
- **افتح Issue:** ناقش التغييرات الأكبر أو القيود القابلة لإعادة الإنتاج قبل التنفيذ.
- **أرسل Pull Request:** اجعل التغيير مركزًا وشغّل أوامر CI الحالية.

Legocraft مفتوح المصدر تحت رخصة MIT. يمكنك عمل fork وتعديله وتوسيعه وإعادة توزيعه وفق شروط [`LICENSE`](LICENSE). راجع [`CONTRIBUTING.md`](CONTRIBUTING.md) لسير المساهمة.

ليست كل مساهمة مفيدة بحاجة إلى كود. يمكن للمصممين والفنانين التقنيين اقتراح هياكل جاهزة، تراكيب مكانية، مفاهيم أشكال جديدة، تدفقات تفاعل، تحديات بناء أو تحسينات وصول عبر GitHub Issue. الرسومات التخطيطية والمخططات والتصاميم المرجعية وملاحظات السلوك الواضحة مفيدة عندما تصف شيئًا متوافقًا مع أداة البناء الحالية.

تُنسب المساهمات المقبولة عبر سجل Git وسجل Pull Requests؛ ويجب الإشارة إلى أصحاب المقترحات في نقاش التنفيذ عندما يحول شخص آخر فكرة مقبولة إلى كود.

### حدود WebXR / Quest

يتضمن Legocraft بالفعل تفاعل WebXR تجريبيًا، وإدخال وحدات التحكم، والحركة، والاهتزازات، وقوائم VR، وتدفقات بناء خاصة بـ XR. لا يزال التحقق على أجهزة Meta Quest الحقيقية مفتوحًا. طبقة XR موثقة ومصممة لتكون قابلة للتوسعة لمن يريد اختبارها أو تحسينها أو تحسين أدائها أو دفعها أبعد.
