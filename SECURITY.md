# Security Policy

Legocraft is currently an experimental open-source project and does not yet publish versioned security support guarantees.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue before the maintainer has had a chance to review them.

If GitHub's private vulnerability reporting is available for this repository, use it. Otherwise, contact the repository maintainer privately through the contact information available on the maintainer's GitHub profile.

## Scope

Security reports are most useful when they include:

- affected browser or environment
- reproduction steps
- impact
- proof of concept where appropriate
- suggested mitigation, if known

General bugs and feature requests should use GitHub Issues instead.
